# 扫描模块测试基线

## 首轮自动化用例

1. 隐藏文件与隐藏目录：名称以 `.` 开头的文件、目录及其子树均不进入扫描、删除、移动或匹配计划。
2. 分类：主流视频扩展名归为 video；主流图片扩展名归为 image；NFO、字幕、压缩包、文本等归为 other。
3. 同层 poster：仅同目录视频/图片可匹配；`-poster`、空格、`-`、`_`、`.` 的归一化规则一致。
4. 一个视频多图：预览必须要求人工选择最终 poster；未选图片只能列为删除候选。
5. 一图多视频：归为冲突，图片不保留且列为删除候选，相关视频标记无 poster。
6. 计划只读：扫描阶段不得调用删除、rename、copy、move 等写操作。
7. 上移预览：子目录保留项只生成 from/to 映射；重名策略在执行阶段前可见。

## 执行方式

使用 Node 内置 `node:test`，命令：`npm test`。测试文件放在 `test/**/*.test.mjs`；媒体样例放在 `test/fixtures/`，不放真实敏感媒体。

## 后续人工验收

- 扫描包含 `.DS_Store`、隐藏目录的工作区，确认其完全不显示且目录不被删除。
- 使用视频、同名图、`-poster` 图、孤立图、NFO/SRT 构造目录，确认仅计划预览而不改动任何文件。
- 使用多个归一化同名视频验证一图多视频冲突显示。
